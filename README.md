# Branch Timeline

## Mac App 预览

[Mac App](mac-app/README.md) 0.3.10 提供大表盘计时、菜单栏与置顶悬浮条，以及共享日/周/月日历、项目目标和统计。顶部可编辑节律；底部“更多”包含锚点树与手牌、成就、人生和完整分支操作。复杂页面离线复用插件组件，直接共用原 state.json 与项目 Markdown，不要求 Obsidian 运行。同时使用时请重载配套插件 0.3.66。

## 使用

重载 Obsidian 后，点击左侧的分支图标打开时间线。也可以在命令面板使用：

- 分支时间线：打开时间线
- 分支时间线：打卡习惯
- 分支时间线：记录项目工时
- 分支时间线：记录分类时长
- 分支时间线：添加项目待办

项目来自全库中匹配设置里 type 的笔记。插件独有数据保存在 `99_assets/branch-timeline/state.json`。

“记录项目工时”先选项目，再决定是否打开“关联任务”。打开后可搜索该项目笔记中未完成的 `- [ ]` 任务，或新建任务；关闭时只记录普通项目工时。插件会记住每个项目上次关联的未完成任务，以及新建任务上次放入的标题。设置中的“项目任务标题”可填多个标题（每行一个），每个标题下的次级标题也会参与搜索和新建位置选择。任务旁的 `（累计 Nh）` 由时间线记录重算；项目日志的明细带 `@任务名`，改备注会更新同一条明细。

设置 → 数据 → 项目笔记注释可选择新同步标记使用 HTML `<!-- -->` 或 Obsidian `%% %%`；旧格式始终可读，改设置不会批量改写旧笔记。“在编辑视图隐藏插件标记”只改变显示，不删除原文。若想统一旧标记，在命令面板运行“转换项目笔记的插件注释格式”：命令会先显示涉及的文件和标记数量，确认后仅转换插件能识别的项目日志与任务标记；普通注释和代码块不变。转换可以撤回，也可以切换格式后再次运行命令。

标签可在插件设置中新增、重命名、映射周记分类、改色和删除。删除标签不会删除已有时间记录。

最右侧细线显示日内专注倾向，不是当天脑力测量值：取所看日期之前 42 天的记录，按同一钟点平滑，较近日期权重较高。项目事实提供适度的专注基线；走神按程度和局部频率降低它；手动状态可在未计时时记录红到蓝之间的连续分值。一天中未记录的时段按中性处理，整天没有相关记录则不作为样本，脑不适点不参与此分值。少于 7 个有效日期，或某时段少于 4 天有直接证据时，细线保持灰色。统计页右侧使用同一模型；短刻度和点仍表示当天实际记录。

“人生”是独立的纵向时间线：右上角添加节点或阶段；在线上双击空白也可按所在日期添加。可按年、月或日记录不确定的往事，缩放时相近节点会合并。精确到某一天且已有周记的节点可直接打开对应周记，并定位到当天标题；插件不会改写周记内容。

切换或再次点击顶部页面标签会回到今天；人生页还可点击“今天”或时间尺度切换按钮。放大到周尺度后，仅现有周记显示周刻度，点击即可打开。设置里的“人生页日记格式”按 `{内容}` 提取节点，默认读取 `[event] {内容}`；在周记里改动后页面会更新，点击提取的节点会定位到原文。此联动只读，不会自动创建旧周记。

在周记正文输入单个 `[` 时，编辑器会按已有周记中的方括号词提供模糊补全；输入第二个 `[` 仍由 Obsidian 的双链补全接管。候选自动排除待办、脚注、链接和代码，不受“人生页日记格式”限制。

时间轴支持：

- 双击空白添加代办；移动端连续轻点两次执行相同操作。
- 长按空白添加分支。
- 上下拖动事项修改时间，左右拖动切换主线或分支。
- 拖动事实顶部与底部调整开始、结束时间。
- 拖动分支起点、终点和 `↔` 控件调整分支。
- `Ctrl/Command + 滚轮`、双指缩放或左下角按钮缩放时间轴。
