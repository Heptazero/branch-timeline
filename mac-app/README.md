# Branch Timeline for Mac · 0.3.10 preview

原生 macOS 13+ App，首版构建为 Apple Silicon。无需服务器。

## 使用

1. 先重载配套插件0.3.66+，或关闭Obsidian。较旧插件可能丢弃新增的月目标；更旧插件还不认识共享计时字段，不可同时写入。
2. 启动App，优先读取上次位置、旧版已选位置，或唯一启用此插件的Obsidian库。识别不唯一时只需选择一次原有state.json；不是创建新库。
3. 顶部搜索并选择进行中的项目（active/doing/进行中），填写本次标题；其他状态仍保留在项目页和历史统计中。拖动大表盘，顺时针选择5分钟一格的倒计时；十二点方向的0表示正计时。点击数字可精确调整分钟数，最多1440分钟；记住上次开始时的项目和时长。
4. 左上角收起图标控制置顶悬浮条。蓝点记录高度专注，红点选择分神程度；方块结束保存，取消位于更多菜单且不生成工时。倒计时到点暂停并打开结束备注确认；返回后可明确继续。
5. 结束时修改标题、写备注，直接写入原时间线与项目日志；Obsidian不必运行。第二个Tab从原时间线读取记录，支持日期切换、连续缩放/触控板捏合、备注详情和指定在Obsidian打开项目文件；首次进入使用今天，切换页面保留共享日期，再点当前Tab定位今天。缩放改变时间坐标和跨度，文字保持原字号。
6. 小窗恢复标准关闭/最小化/缩放按钮；关闭只隐藏窗口，计时仍继续。菜单栏使用原生菜单。菜单栏退出、主窗口退出、⌘Q、Dock退出进入同一保存流程；保存失败可返回或明确选择仍然退出。

时间线、项目、统计共享顶部正中的日期与日/周/月切换，页面内容滚动时保留在顶部，跨页保留日期，再点当前Tab回今天。项目页另保留累计范围；点击日期选择具体日期/周，月范围使用12个月选择器，跨月切换从月初定位，避免月底天数不同而跳错。

日视图左实际、右计划；计划默认展开，可由右上角双栏图标隐藏并记住选择，两侧均可双击添加。计划使用待办及预计结束时刻，不生成事实工时或项目完成日志。周视图一列一天，日期标题固定，窄窗口横向滚动；当日有浅色底。月视图一格一天、项目分色堆叠柱表示实际工时，点击日期查看项目排行并可打开当天时间线。

已结束的时间块和未开始的计划可长按约0.35秒后上下拖动整体移动，保持时长并限制在同一逻辑日；独立上下手柄调整边缘。整体移动事实时同步平移关联红/蓝标记，更新带唯一标记的项目日志；暂停/进行中的计时块须先结束。

右上角齿轮或⌘,打开设置，显示App实际数据路径、Obsidian配置路径、项目类型配置及磁盘插件版本的兼容状态。核对的是本机磁盘配置，不是其他设备的同步状态；计时中不可切换数据源。

日期按钮弹出共用的月历热力图，颜色按当天记录总时长，今天与选中日期/周分别标记。点日期跳转，月历里的今天按钮定位当前逻辑日。

关闭主窗口不会退出；退出 App 和 Mac 休眠会暂停。异常退出后恢复至最近检查点并暂停，最多可能缺失约15秒，不会将整个离线时间自动算成工时。

## 数据边界

- 唯一主数据：现有插件配置中的statePath。既有days、项目、锚点、节律等原地保留，App还保存macTimer检查点与desktopReceipts去重回执；本机偏好只记文件位置和窗口位置。
- 旧`~/Library/Application Support/BranchTimelineMac/archive.json`只读保留为备份。首次接入时处理旧版未写回记录；已导入回执防止恢复被主动删除的事实。之后不再新增独立归档或收件箱文件。
- App和插件复用同一份TypeScript的事实分段、Markdown日志格式化逻辑，构建时打包给系统JavaScriptCore执行。Swift负责原生界面和文件访问；复杂功能离线复用同一份时间线组件，使用受限的本地文件适配器，不加载网站。
- Mac本机使用同一路径文件锁串行保存，并在替换前检查原文。项目日志失败不提交时间线；状态失败只在项目原文仍匹配时回退。跨文件不保证断电/崩溃绝对原子，重试以固定编号去重。
- 设置 → 计时中可开关“结束时忽略短计时”，默认60秒，可填1–3600秒；关闭后保留短于一分钟的有效计时。开始时保存阈值，只影响新计时。结束时不足阈值直接忽略，不弹备注；暂停不计入。新记录保留秒级时长，以分钟小数存入原时间线，02:00跨日拆分；旧会话沿用原分钟取整。
- 该锁只保护同一Mac上遵守协议的新客户端。跨设备仍由你的同步工具负责，不声称解决Syncthing并发冲突。

## 功能范围

已包括：可拖动的大面积扇形表盘、正计时/倒计时、项目模糊检索、暂停/继续、结束备注、红蓝状态点、原生菜单栏、置顶悬浮条和共享数据直接保存。

项目页：日/周/月/累计、状态筛选、时长排序、已做/目标进度条，条内左端已做、右端目标，无目标显示“无”；百分数在标题右侧。点击目标数字就地展开编辑，输入直接校验，不依赖失焦事件提交，均匀进度线按逻辑日计算。每日、每周、每月目标分别保存生效断点并向后沿用，不改之前或覆盖之后已设定的目标。未单独设置月目标时采用当月每日目标之和，不擅自将周目标乘四。点击项目名称前的颜色点打开调色板，保存后写入项目Markdown的color属性，时间块和统计同步使用该颜色。

统计页：所选日/周/月的总记录时长、按项目分色的每日堆叠柱、项目工时排行、计时分钟/走神记录数、完整睡眠记录与所选范围平均虚线。无走神只显示“未记走神”，不推断完美专注；红蓝预测不再混入工时条。沿用插件原有计算函数，当前原生计时的有效分钟会只读投影到视图中，暂停间隙不计入；完成后不重复计算。

原生时间线支持双击空白处补记时间块，拖动上沿/下沿修改开始/结束时间；正在计时的记录须先结束。拖动按5分钟吸附，默认新块30分钟；创建沿用项目/标签强制设置。点击块的“更多操作”进入原有完整菜单。时间线右上角菜单切换分支视图；锚点、成就、人生、完整项目面板和详细统计在底部“更多”。这些页面离线复用插件原有组件，支持原来的新增、编辑、关联、拖拽和撤回。顶部节律入口增删改固定时间；日历中的节点可完成、原位撤销、拖动或修改时间。其他应用全屏、多个桌面、睡眠唤醒与真实触控/键盘体验需要本机验收。锁屏不提供覆盖层。

尚未接入真实硬件。传输层将调用同一套开始、暂停、继续、标记、结束操作，并沿用会话UUID；硬件不能独立追加一份工时。需先确认设备型号/协议。USB/BLE、断连补传和自动重连不在本版伪装成可用功能。

## 构建与检查

需要 Apple Swift Command Line Tools。无第三方 Swift 依赖。

```sh
node mac-app/scripts/build.mjs
node scripts/build-native-bridge.mjs
swift run --package-path mac-app CoreChecks
```

CoreChecks 是无需完整 Xcode/XCTest 的临时文件测试工具。源码每文件500行以内。

生成 `mac-app/dist/Branch Timeline.app` 和 ZIP。本机临时签名，不是 Developer ID 签名或苹果公证版本。不要为运行预览关闭系统安全保护。

开发者可用 `BranchTimelineMac --render-preview <输出目录>` 渲染隔离的假数据，不加载用户归档、不写真实笔记库、不启动计时。

`BranchTimelineMac --check-quit`只验证打包的共享资源与退出委托，不加载用户数据、不显示主窗口。

`BranchTimelineMac --check-interface`仅用隔离假数据验证标准窗口按钮与时间线文档可缩小，不点击真实界面。

## 日志同步的实际范围

Mac时间线支持双击补记及拖动已结束时间块的起止边缘。补记/结束计时写入state.json及关联项目Markdown，不要求Obsidian运行。拖动带唯一日志标记的时间块同步修改日志的时间、时长及项目/任务累计，保留日志原有文字、双链和注释格式；无日志标记的旧事实仅改时间线。历史标题编辑、删除仍未移植。

拖动期间本地预览、松手保存；保存前检查原记录版本。其他客户端修改过记录或日志有冲突时拒绝覆盖。每块限制在02:00至次日02:00，拖动按5分钟吸附，不跨逻辑日。

旧Obsidian插件支持更新关联日志的备注、删除带唯一标记的工时日志、切换项目时迁移日志；标题重命名及拖动时间目前主要更新state，不能视为完整的日志编辑同步。手动修改Markdown不会反向更新state。

当前未取消项目日志输出、未改存储策略。若要实现完整双向编辑，需先明确主数据源及冲突规则，不能把现在的部分同步描述为已完成。

完整组件仍读写同一 state.json 和配置，不要求 Obsidian 运行。点击原生项目名称打开完整分支详情；文件入口可在 App 只读定位，或明确在 Obsidian 中编辑。页面开关沿用原设置，右上“全部功能设置”可恢复隐藏页面。打开锚点等页面本身不会重写项目 Markdown。右上刷新会更新完整组件的目录缓存；修改文件后可手动刷新。

`BranchTimelineMac --check-features`在临时笔记库和隐藏 WebKit 窗口检查页面加载、锚点创建/撤回、父子树破戒、设置保存、项目详情和节律。只读状态/配置/Markdown；写入限制同一库中的 Markdown 与已配置的数据文件，使用原文比较、文件锁和原子替换，保护原生计时与去重字段。不会访问网络或授权任意系统文件。

日志同步沿用原组件边界：并非任意 Markdown 手改都能反向更新时间线；完整菜单的部分旧操作也不保证全字段同步。新表盘和分支页的逐条计时是两种入口，避免同时开启两段计时；原表盘不会把分支页的旧计时显示成表盘会话。当前没有苹果日历桥接、硬件或 AI 提醒。

底部导航随窗口宽度逐项展开，优先保留排在前面的页面，放不下的收进“更多”。按住约0.3秒再拖动可排序，松手保存；取消不保存。右键“收进更多”会记住手动收起，即使拉宽也不自动恢复；更多列表右侧图钉将该页恢复到底部最前。顺序与图表偏好只保存在本机，不改共享时间线数据。

统计“项目”右上可切换条形图／饼图，沿用同一日/周/月范围与排序。条形图显示每日分布和项目排行，饼图显示项目工时占比，点击扇区或列表高亮。两图使用相同的各项目记录工时之和，包括未关联或不在项目目录里的记录；重叠计时按各项目分别累计，与不重复的墙钟时长不同。走神与睡眠视图保持原样。

计划块右侧的计时图标直接开始正计时，继承标题、项目、备注和关联元数据；须关联进行中项目。结束只新增实际记录，原计划及项目任务勾选状态保持不变，可反复执行。计划时长仍留在右侧作对照，不限制执行时间。旧版未结束的计划会话也按正计时显示；普通表盘已选倒计时时长不被计划启动改写。

实际记录保留 sourcePlanId/sourcePlanDate 关联，去掉计划时间字段以避免虚影重复。计时中修改原计划不阻塞保存，也不覆盖它；删过的计划不会恢复。记录到项目日志并重算工时累计，但不自动打勾。取消或被短计时规则忽略时保留计划。关联任务缺失时仍可选独立保存实际记录。
统计总时长与“项目／走神／睡眠”、图形切换固定在滚动区外，两种图形切换时标题与按钮不会随图形高度跳动。

日界线目前固定为02:00，Mac日时间线显示02:00到次日02:00，与起床/入睡标记独立；跨过02:00的计时拆为两个日期的事实。起止边缘与详情可以查看时间。

Mac可以在Obsidian及插件停用时独立读写数据与项目Markdown；仍读取 `.obsidian/plugins/branch-timeline-hz/data.json` 的共享设置。停用插件即可，不要删除该目录；打开项目文件的入口仍指定Obsidian。

默认时间线现在直接显示已保存与正在计时的专注／走神点。点击状态点可修改时间或删除；正在计时的点需先结束。右上角加号可独立记录可用脑力，或添加带名称与颜色的精力区间；分界左端可拖动，右侧菜单可编辑。精力安排从所选日期起沿用，过去的日期不改。空档中央可直接补记，里程碑显示旗标。

右侧细线与统计“时间图”使用同一份历史预测：只读此前42天、按近期加权；至少7个有记录的历史日且该时段至少4天有证据才着色，否则为中性灰。它不把未记录的时间判断为走神，也不代表当天实时状态。时间图合并睡眠、实际计时和状态点，虚线为平均入睡与起床。
