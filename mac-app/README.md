# Branch Timeline for Mac · 0.1.0 preview

原生 macOS 13+ App，首版构建为 Apple Silicon。无需服务器。

## 使用

1. 启动 App，选择已有 Obsidian 笔记库。只读取项目；不会迁移历史数据。
2. 搜索项目，填写本次标题与目标分钟数；0 表示不设本次目标。
3. 开始计时。主窗口右上角图钉可显示/隐藏悬浮条；菜单栏也能进入。
4. 可暂停/继续、记录红蓝状态点。方块为结束并保存，叉号为取消且不生成工时。
5. 结束后可修改标题、写备注。记录先保存本机，再排队写回笔记库。
6. 配套 Obsidian 插件 0.3.57+ 在 Mac 运行时自动导入，也可执行“导入 Mac App 计时记录”。App 会显示已导入或失败原因，不能将排队状态当成已同步。

关闭主窗口不会退出；退出 App 和 Mac 休眠会暂停。异常退出后恢复至最近检查点并暂停，最多可能缺失约15秒，不会将整个离线时间自动算成工时。

## 数据边界

- 本机原始记录：`~/Library/Application Support/BranchTimelineMac/archive.json`。包含秒级起止、暂停分段、状态点。格式损坏或被另一进程修改时拒绝覆盖。
- 笔记库只由 App 新建独立的 `desktop-inbox/<UUID>.json`；路径从插件实际配置的 statePath 推导。App **不直接写**插件 state.json 或项目 Markdown。
- 插件复用原来的项目/时间线双写保护；用固定编号和回执去重。完成后删除时间线事实不会被下一次扫描复活。程序崩溃时跨文件写入不保证绝对原子，原始源记录一直保留，可重试导入。
- 插件仍是分钟精度：按整段累计的有效秒数向下取整，不把暂停计入；不足一分钟不会造事实，秒级原始记录保留。02:00跨日切分。
- 只在 Mac 消费收件箱；iOS不会再次消费同一批记录。不是一套新的跨设备冲突解决系统。

## 首版范围

已包括：项目模糊检索、秒级计时、暂停/继续、结束备注、红蓝状态点、菜单栏、原生悬浮窗口、本地恢复、排队写回和状态回执。

尚未移植完整时间线/锚点/统计界面；仍在 Obsidian 中使用。其他应用全屏、多个桌面、睡眠唤醒与真实触控/键盘体验需要本机验收。锁屏不提供覆盖层。

尚未接入真实硬件。传输层将调用同一套开始、暂停、继续、标记、结束操作，并沿用会话UUID；硬件不能独立追加一份工时。需先确认设备型号/协议。USB/BLE、断连补传和自动重连不在本版伪装成可用功能。

## 构建与检查

需要 Apple Swift Command Line Tools。无第三方 Swift 依赖。

```sh
node mac-app/scripts/build.mjs
swift run --package-path mac-app CoreChecks
```

CoreChecks 是无需完整 Xcode/XCTest 的临时文件测试工具。源码每文件500行以内。

生成 `mac-app/dist/Branch Timeline.app` 和 ZIP。本机临时签名，不是 Developer ID 签名或苹果公证版本。不要为运行预览关闭系统安全保护。

开发者可用 `BranchTimelineMac --render-preview <输出目录>` 渲染隔离的假数据，不加载用户归档、不写真实笔记库、不启动计时。
